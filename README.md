# GoogWare (Terra Prep W2)

![Gooog](https://cdn.hackclub.com/01a1194a-9475-7c9d-963e-ea5009d4e52b/Screenshot%202026-10-07%20221336.png)

A game written in Godot where you attempt to finish all levels without losing a life! It's like WarioWare. :)

There is 3 levels in this game! A clicker, a platformer and a short simple quiz.

This game was made with the help of the "Make a WarioWare Game" guide on [Stardance](https://stardance.hackclub.com/missions/wario-ware).

## How 2 Play?

Just click on this [nice link](https://missanonymous.itch.io/googware) and enjoy the game!
